# Agent 内部媒体处理

这些是供 Agent 执行的操作，不作为用户操作说明。

## 一次性准备

在用户选择的课程项目中使用 `scripts/setup_media.py --workspace <项目绝对目录>`。它只在该项目的 `.runtime` 或 `.good-student-runtime` 虚拟环境安装本地转写与 OCR 组件，不修改全局 Python。依赖可能需要联网，按宿主工具的权限规则处理。

`scripts/student.py` 会自动选择同项目的运行环境，并将语音与 OCR 模型缓存放在该环境下。打包技能不包含 Python、第三方引擎和模型；首次使用由 Agent 准备。网络不可用或宿主完全禁止执行工具时，不能宣称完成自动识别，可以先处理用户已有文本。

## 录音

以 `kind=audio` 导入常见录音文件，会自动调用本地 faster-whisper，保留真实片段时间。默认中文 CPU 转写；可用 `GOOD_STUDENT_WHISPER_MODEL` 指定模型名或本地模型路径，`GOOD_STUDENT_AUDIO_LANGUAGE` 指定语言或 auto。首次使用下载模型，之后缓存复用。

只有用户已明确说明整份录音为教师发言时，才声明 speaker=teacher；转写本身不识别说话人身份。不要将学生发言和问句当成教师考试承诺。

中途失败会保留已处理片段。用内部 `media-retry --source ...` 恢复。只报告实际完成范围，不把沉默区间或未上传的课次补成文字。

## 扫描件与图片

PDF 逐页优先读取原生文字，需要时渲染并调用本地 RapidOCR；截图和扫描图片直接识别。保留实际页码、文字框和识别置信信息。部分页失败或文字不清时状态为 partial，不把第一页成功当整份成功。

如果宿主提供读图工具，可以结合原图核对低置信内容和复杂公式；宿主没有视觉能力时说明不清的位置。不要用常识补写看不清的试题、数字或公式。

## 结果与重试

`import` 自动完成识别并返回元数据；原文使用 `source-show` 分段读取。完整原件始终留存在相应课程。导入后缺少引擎或网络时会保留资料并提示待处理，环境准备好后 `media-retry`；不要要求用户重新上传已经留存的文件。
