# 好学生 Agent

把资料交给 Agent，在本地工作台复习。适用于 Codex、DeepSeek harness 等能加载技能并执行本地工具的 Agent。

## 怎么开始

将技能包解压后放入所用 Agent 的技能目录，或者让 Agent 直接读取 `good-student` 文件夹中的 `SKILL.md`。

然后直接说：

> 用好学生帮我复习数据结构，选速通模式，卷面 60 分。这些是我的 PPT、往年题和几节课的录音。

你不需要运行代码或输入命令。

## 可以提供什么

- PPT、教材、笔记、往年题和自测题。
- 手机录音、豆包逐字稿或纪要。
- 扫描 PDF、试卷照片和截图，Agent 会自动识别文字。

资料可以分批添加。没有录音、只有几节课的录音，都可以开始；不需要补齐全学期录音。

## 选择复习方式

- **高分**：全面梳理现有课程资料，加强重点与薄弱内容。
- **速通**：以卷面及格为目标，先学重点与必要基础，同时保留课程主线。默认百分制 60 分，也可以自己指定及格线。

老师明确强调的内容和你指定的内容会单独记录。没有录到的章节不会因此被当作不考。

## 你会得到什么

Agent 会打开本地界面。选择资料路径和复习模式后，一次准备课程讲解、知识脉络与思维导图、重点清单、练习与解析，保存在本地。

之后可以自由跳章节、搜索和展开解析，不必反复说“继续”，也不需要翻聊天记录。答案默认折叠，学习记录和错题持续保存，可导出复习包。

首次生成会在界面确认：允许将本课程选中的资料发送给已登录的 Codex（OpenAI）分析。确认后自动接单，记住这些资料；新增资料或换课程会再确认，也可撤销。无需另外填写 API 密钥。

界面显示真实进度、可估算的阶段完成时间和错误来源。中断时保留成果；Codex 未安装、未登录或额度不足时说明具体原因，已有资料照常可读。

练习分为你提供的原题与 Agent 模拟题。资料已有答案时原样使用；缺答案时优先依据本课资料并注明出处。可以质疑答案，复核另存版本并保留原答案。

首次处理录音和扫描件时，Agent 会准备所需组件和模型。识别在本地进行；听不清或看不清的部分会标出来，请你核对。
